# Day 02 - Python Guessing Game

## Deskripsi

Project sederhana berupa permainan tebak angka menggunakan Python.

User harus menebak angka yang telah ditentukan oleh program.

## Fitur

Program memiliki beberapa fitur:
- User memasukkan tebakan
- Program mengecek tebakan user
- Memberikan informasi apakah tebakan benar atau salah
- User dapat mencoba menebak kembali

## Cara Menjalankan

Jalankan program dengan perintah:

```bash
python3 guessing_game.py
