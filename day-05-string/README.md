## Mini Project

### Program Pengolah Nama

Program menerima nama dari user kemudian mengolahnya menggunakan berbagai operasi String.

Fitur program:

- Menghapus spasi berlebih
- Mengubah nama menjadi huruf besar
- Mengubah nama menjadi huruf kecil
- Mengubah format nama dengan `title()`
- Menghitung jumlah karakter
- Mengambil karakter pertama
- Mengambil karakter terakhir
- Mendeteksi apakah nama terdiri dari satu atau beberapa kata
