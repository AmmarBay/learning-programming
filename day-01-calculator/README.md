# Day 01 - Python Calculator

## Deskripsi

Project sederhana untuk membuat kalkulator menggunakan Python.

Project ini dibuat sebagai latihan dasar Python, khususnya penggunaan:
- Variable
- Input
- Output
- Operator aritmatika
- Perhitungan sederhana

## Fitur

Kalkulator dapat melakukan operasi matematika dasar:
- Penjumlahan
- Pengurangan
- Perkalian
- Pembagian

## Cara Menjalankan

Jalankan program dengan perintah:

```bash
python3 calculator.py
