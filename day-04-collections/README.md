# Day 04 - Python Collections

## Materi
Pada Day 04 mempelajari Python Collections:

- List
- Tuple
- Dictionary
- Set
- Perulangan `for`
- `len()`
- `sum()`
- Percabangan `if/else`

## Contoh
Program menggunakan List untuk menyimpan nilai mahasiswa:

- 80
- 85
- 90
- 75
- 95

## Hasil

Total nilai: 425

Rata-rata nilai: 85.0

Status: Lulus

## Mini Project

Mini project membuat program data mahasiswa menggunakan:

- Dictionary untuk data mahasiswa
- List untuk menyimpan nilai
- Set untuk menyimpan mata kuliah
- `for` untuk menampilkan nilai
- `sum()` dan `len()` untuk menghitung nilai
- `if/else` untuk menentukan status kelulusan
